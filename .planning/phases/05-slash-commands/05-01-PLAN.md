# Plan 05-01: Slash Command Skills for `/tt`

**Phase:** 5 — Claude Code Slash Commands
**Goal:** Create 7 Claude Code skills that surface time tracking status and control inside conversations

## Context

Claude Code skills live in `.claude/skills/<name>/SKILL.md`. The `!`command`` syntax executes shell commands as preprocessing, embedding live output in the prompt. All skills invoke the compiled `./dist/tt` binary with `NO_COLOR=1` for clean text.

## Tasks

### Task 1: Create `/tt` status skill (CLCD-01, CLCD-07)

**Create** `.claude/skills/tt/SKILL.md`

```markdown
---
name: tt
description: Show current time tracking status — active session, project, duration, today's total
disable-model-invocation: true
---

Current time tracking status:

!`NO_COLOR=1 ./dist/tt now 2>&1`

Present this status to the user concisely. Include the project name, running duration, and today's total. If no session is active, let the user know and suggest `/tt:start`.
```

**Verify:** File exists at `.claude/skills/tt/SKILL.md` with correct frontmatter.

Edit result:

!`NO_COLOR=1 ./dist/tt edit $ARGUMENTS 2>&1`

!`NO_COLOR=1 ./dist/tt log --from today 2>&1`

If the edit command above failed (e.g., "Session ID required" or "No changes specified"), show the recent sessions list and guide the user. They should re-invoke with: `/tt:edit <session-id> --start HH:mm` (or `--end`, `--project`, `--note`, `--tag`, `--untag`).
