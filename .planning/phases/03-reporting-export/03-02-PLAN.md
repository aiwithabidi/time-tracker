**1a. Create `src/core/export/csv.ts` -- RFC 4180 CSV utilities:**

```typescript
export const CSV_HEADERS = [
  'project', 'date', 'start_time', 'end_time',
  'duration_hours', 'duration_human', 'notes', 'tags',
] as const

export function escapeCSVField(value: string): string {
  if (value.includes(',') || value.includes('"') || value.includes('\n')) {
    return `"${value.replace(/"/g, '""')}"`
  }
  return value
}

export function toCSVRow(fields: readonly string[]): string {
  return fields.map(escapeCSVField).join(',')
}
```

interface SessionWithDetails {
  readonly session: Session
  readonly projectSlug: string
  readonly projectName: string

Create `createExportService(repos: Repositories)` with two methods:

- `getSessionsForExport(options: { from?: number; to?: number; projectSlug?: string }): SessionWithDetails[]`
  - If `projectSlug` provided, look up project by slug via `repos.projects` (add a `findBySlug` if needed, or iterate). Get the projectId. Pass to `repos.sessions.findByDateRange(from, to, projectId)`.
  - If no `projectSlug`, call `findByDateRange(from ?? 0, to ?? Date.now())`.
  - For each session: look up the project (for slug/name), call `repos.notes.findBySession(session.id)` for notes, `repos.tags.findBySession(session.id)` for tags.
  - Return `SessionWithDetails[]` sorted by startTime ascending.

- `toCSV(sessions: SessionWithDetails[], timezone: string): string`
  - Build header row using `toCSVRow([...CSV_HEADERS])`.
  - For each session, compute:
    - `project`: projectSlug
    - `date`: `DateTime.fromMillis(session.session.startTime).setZone(timezone).toISODate()`
    - `start_time`: `DateTime.fromMillis(session.session.startTime).setZone(timezone).toFormat('HH:mm')`
    - `end_time`: if endTime, format same way; otherwise `'active'`
    - `duration_hours`: `((endTime ?? Date.now()) - startTime - idleDeductedMs) / 3_600_000` formatted to 2 decimal places
    - `duration_human`: use `formatDuration(durationMs)` from `src/cli/format.ts`
    - `notes`: join note contents with `'; '`
    - `tags`: join tag values with `', '`
  - Join all rows with `'\n'` and add trailing `'\n'`.

- `getDryRunSummary(sessions: SessionWithDetails[]): { count: number; totalMs: number }`
  - Count sessions. Sum durations using `(s.session.endTime ?? Date.now()) - s.session.startTime - s.session.idleDeductedMs`.

**2a. Create `src/cli/commands/export.ts`:**

```typescript
import { define } from 'gunshi'
import { DateTime } from 'luxon'
import { getDb } from '../../db/client'
import { createRepositories } from '../../db/repositories/index'
import { createExportService } from '../../core/export/export-service'
import { parseDateFlag } from '../date-parsing'
import { formatDuration, errorOutput } from '../format'
import { handleCommandError } from '../helpers'

const exportCommand = define({
  name: 'export',
  description: 'Export time data (usage: tt export csv [flags])',
  args: {
    project: { type: 'string', short: 'p', description: 'Filter by project slug' },
    from: { type: 'string', description: 'Start date (YYYY-MM-DD or keyword)' },
    to: { type: 'string', description: 'End date (YYYY-MM-DD or keyword)' },
    'dry-run': { type: 'boolean', description: 'Preview without outputting CSV' },
  },
  run: (ctx) => {
    try {
      // "csv" is passed as positional: tt export csv [--flags]
      // positionals[0] = "export", positionals[1] = "csv"
      const format = ctx.positionals?.[1]
      if (format !== 'csv') {
        errorOutput(`Usage: tt export csv [--project=x] [--from=DATE] [--to=DATE] [--dry-run]`)
        process.exitCode = 1
        return
      }

      const db = getDb()
      const repos = createRepositories(db)
      const exportService = createExportService(repos)
      const timezone = DateTime.local().zoneName ?? 'UTC'

      const fromDate = ctx.values.from
        ? parseDateFlag(ctx.values.from).toMillis()
        : undefined
      const toDate = ctx.values.to
        ? parseDateFlag(ctx.values.to).endOf('day').toMillis()
        : undefined

      const sessions = exportService.getSessionsForExport({
        from: fromDate,
        to: toDate,
        projectSlug: ctx.values.project,
      })

      if (sessions.length === 0) {
        process.stderr.write('No sessions found matching the given filters.\n')
        return
      }

      if (ctx.values['dry-run']) {
        const summary = exportService.getDryRunSummary(sessions)
        const durationStr = formatDuration(summary.totalMs)
        const projectSuffix = ctx.values.project ? ` for ${ctx.values.project}` : ''
        process.stderr.write(
          `Would export ${summary.count} session${summary.count !== 1 ? 's' : ''} (${durationStr})${projectSuffix}\n`
        )
        return
      }

      const csv = exportService.toCSV(sessions, timezone)
      process.stdout.write(csv)
    } catch (error) {
      handleCommandError(error)
    }
  },
})

export default exportCommand
```

Key behaviors:
- Only `csv` format supported; reject others with clear error.
- CSV goes to `process.stdout.write()` so it can be piped: `tt export csv > report.csv`
- Dry-run summary goes to `process.stderr.write()` so it never mixes with piped output.
- "No sessions found" message goes to stderr.
- `--to` date uses `.endOf('day')` so the full day is included.

const showBillable = ctx.values.billable === true
const headers = showBillable
  ? ['Project', 'Time', 'Sessions', 'Amount']
  : ['Project', 'Time', 'Sessions']

let billableTotal = 0
const rows = result.projects.map(p => {
  const baseRow = [
    p.project.displayName,
    formatDuration(p.totalMs),
    `${p.sessionCount}`,
  ]
  if (showBillable) {
    const hours = p.totalMs / 3_600_000
    if (p.project.hourlyRate) {
      const amount = hours * p.project.hourlyRate
      billableTotal += amount
      baseRow.push(formatCurrency(amount, p.project.currency ?? 'USD'))
    } else {
      baseRow.push('--')
    }
  }
  return baseRow
})

const footerRow = showBillable
  ? ['Total', formatDuration(result.grandTotalMs), '', billableTotal > 0 ? formatCurrency(billableTotal, 'USD') : '']
  : ['Total', formatDuration(result.grandTotalMs), '']

const table = borderedTable(headers, rows, footerRow)
