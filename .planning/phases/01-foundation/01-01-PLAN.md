# Plan 01-01: Database Schema, WAL Mode, and Drizzle Repository Layer

**Phase:** 1 — Foundation
**Depends on:** Nothing (first plan)
**Requirements:** FNDN-01, FNDN-02, FNDN-03, FNDN-04, FNDN-05, FNDN-06

## Goal

Create the SQLite database with WAL mode, define the complete Drizzle schema (sessions, session_terminals, activity_pulses, projects, session_notes, session_tags), and implement the repository layer with type-safe CRUD operations. This is the data foundation — every subsequent plan depends on these tables and repositories existing.

## Tasks

### Task 1: Project Scaffolding and Dependencies

**File(s):**
- `package.json`
- `tsconfig.json`
- `drizzle.config.ts`
- `src/db/client.ts`

**Action:** Initialize the Bun project and install all dependencies. Create the database client module.

1. Run `bun init` in the project root (if package.json does not exist)
2. Install production dependencies:
   ```
   bun add gunshi drizzle-orm luxon zod chalk
   ```
3. Install dev dependencies:
   ```
   bun add -D drizzle-kit vitest @types/luxon @types/bun
   ```
4. Create `tsconfig.json` with:
   - `"target": "ESNext"`, `"module": "ESNext"`, `"moduleResolution": "bundler"`
   - `"strict": true`, `"skipLibCheck": true`
   - `"paths": { "@/*": ["./src/*"] }`
   - `"outDir": "./dist"`
5. Create `drizzle.config.ts`:
   ```typescript
   import { defineConfig } from 'drizzle-kit'
   export default defineConfig({
     schema: './src/db/schema.ts',
     out: './drizzle',
     dialect: 'sqlite',
   })
   ```
6. Create `src/db/client.ts` — the singleton database connection:
   ```typescript
   import { Database } from 'bun:sqlite'
   import { drizzle } from 'drizzle-orm/bun-sqlite'
   import * as schema from './schema'
   ```
   - Resolve DB path: `path.join(os.homedir(), '.tt', 'tt.db')`
   - Auto-create `~/.tt/` directory if it does not exist (use `mkdirSync` with `recursive: true`)
   - Open `Database` with `{ create: true }`
   - Set PRAGMAs immediately after open:
     - `PRAGMA journal_mode = WAL`
     - `PRAGMA busy_timeout = 5000`
     - `PRAGMA synchronous = NORMAL`
     - `PRAGMA foreign_keys = ON`
     - `PRAGMA cache_size = -32000` (32MB)
   - Export `db` (the drizzle instance) and `sqlite` (the raw Database for transactions)
   - Export a `getDb()` function that lazily initializes on first call (avoid opening DB at import time — hurts startup for commands that may not need DB)
   - Export a `withTransaction<T>(fn: (tx) => T): T` helper that uses `BEGIN IMMEDIATE` for write transactions (critical for multi-terminal concurrency)

### Task 2: Drizzle Schema Definition

**File(s):**
- `src/db/schema.ts`
- `src/db/types.ts`

**Action:** Define all tables using `sqliteTable` from `drizzle-orm/sqlite-core`. This schema must include every field needed through Phase 4 to avoid future migrations breaking billing data.

`src/db/schema.ts` tables:

**projects table:**
```typescript
import { sqliteTable, text, integer, real } from 'drizzle-orm/sqlite-core'

export const projects = sqliteTable('projects', {
  id: text('id').primaryKey(),              // ULID or nanoid
  slug: text('slug').notNull().unique(),     // kebab-case identifier
  displayName: text('display_name').notNull(),
  clientName: text('client_name'),
  hourlyRate: real('hourly_rate'),           // nullable — not all projects are billable
  currency: text('currency').default('USD'),
  gitRemoteUrl: text('git_remote_url'),      // optional, for matching
  directoryPath: text('directory_path'),     // absolute path to git root
  isDeleted: integer('is_deleted', { mode: 'boolean' }).default(false).notNull(),
  createdAt: integer('created_at', { mode: 'number' }).notNull(), // UTC ms
  updatedAt: integer('updated_at', { mode: 'number' }).notNull(), // UTC ms
})
```

**sessions table:**
```typescript
export const sessions = sqliteTable('sessions', {
  id: text('id').primaryKey(),
  projectId: text('project_id').notNull().references(() => projects.id),
  startTime: integer('start_time', { mode: 'number' }).notNull(),  // UTC ms
  endTime: integer('end_time', { mode: 'number' }),                 // NULL = active
  timezone: text('timezone').notNull(),                              // IANA e.g. 'America/New_York'
  source: text('source').notNull(),                                  // 'manual' | 'hook' | 'auto'
  rateAtTime: real('rate_at_time'),                                  // snapshot from project
  idleDeductedMs: integer('idle_deducted_ms').default(0).notNull(),
  isDeleted: integer('is_deleted', { mode: 'boolean' }).default(false).notNull(),
  createdAt: integer('created_at', { mode: 'number' }).notNull(),
  updatedAt: integer('updated_at', { mode: 'number' }).notNull(),
})
```
- Add compound index on `(projectId, startTime)` for report queries
- Add index on `endTime` for finding active sessions (`end_time IS NULL`)

**sessionTerminals table:**
```typescript
export const sessionTerminals = sqliteTable('session_terminals', {
  id: text('id').primaryKey(),
  sessionId: text('session_id').notNull().references(() => sessions.id),
  terminalId: text('terminal_id').notNull(),
  attachedAt: integer('attached_at', { mode: 'number' }).notNull(),
  detachedAt: integer('detached_at', { mode: 'number' }),
})
```
- Add index on `(sessionId, terminalId)` for uniqueness check

**sessionNotes table:**
```typescript
export const sessionNotes = sqliteTable('session_notes', {
  id: text('id').primaryKey(),
  sessionId: text('session_id').notNull().references(() => sessions.id),
  content: text('content').notNull(),
  createdAt: integer('created_at', { mode: 'number' }).notNull(),
})
```

**sessionTags table:**
```typescript
export const sessionTags = sqliteTable('session_tags', {
  id: text('id').primaryKey(),
  sessionId: text('session_id').notNull().references(() => sessions.id),
  tag: text('tag').notNull(),                // kebab-case single word
  createdAt: integer('created_at', { mode: 'number' }).notNull(),
})
```
- Add unique index on `(sessionId, tag)` to prevent duplicate tags

**activityPulses table:**
```typescript
export const activityPulses = sqliteTable('activity_pulses', {
  id: text('id').primaryKey(),
  sessionId: text('session_id').notNull().references(() => sessions.id),
  terminalId: text('terminal_id').notNull(),
  sourceType: text('source_type').notNull(),  // 'hook:session_start' | 'hook:stop' | 'hook:pre_tool' | 'hook:post_tool' | 'manual'
  timestamp: integer('timestamp', { mode: 'number' }).notNull(),   // UTC ms
})
```
- Add index on `(sessionId, timestamp)` for latest-pulse lookups

`src/db/types.ts` — Export inferred TypeScript types:
```typescript
import type { InferSelectModel, InferInsertModel } from 'drizzle-orm'
import type { projects, sessions, sessionTerminals, sessionNotes, sessionTags, activityPulses } from './schema'

export type Project = InferSelectModel<typeof projects>
export type NewProject = InferInsertModel<typeof projects>
export type Session = InferSelectModel<typeof sessions>
export type NewSession = InferInsertModel<typeof sessions>
// ... etc for all tables
```

Use `nanoid` (via `crypto.randomUUID()` or Bun's built-in) for all IDs. Prefer `crypto.randomUUID()` since it is built into Bun with zero deps.

### Task 3: Repository Layer

**File(s):**
- `src/db/repositories/project-repository.ts`
- `src/db/repositories/session-repository.ts`
- `src/db/repositories/pulse-repository.ts`
- `src/db/repositories/note-repository.ts`
- `src/db/repositories/tag-repository.ts`
- `src/db/repositories/index.ts`

**Action:** Create repository modules for each entity. Each repository is a plain object with functions (not a class) that takes the db instance. All write operations use `withTransaction`. All queries filter `is_deleted = false` by default.

**ProjectRepository** (`project-repository.ts`):
- `findBySlug(slug: string): Project | undefined`
- `findByDirectoryPath(dirPath: string): Project | undefined`
- `findAll(): Project[]`
- `create(data: NewProject): Project`
- `update(id: string, data: Partial<Project>): Project`
- `upsertFromDirectory(slug: string, dirPath: string, displayName: string): Project` — find-or-create pattern for auto-inferred projects

**SessionRepository** (`session-repository.ts`):
- `findActiveByProject(projectId: string): Session | undefined` — `WHERE end_time IS NULL AND is_deleted = false AND project_id = ?`
- `findActiveAll(): Session[]` — all sessions where `end_time IS NULL AND is_deleted = false`
- `findById(id: string): Session | undefined`
- `findByDateRange(from: number, to: number, projectId?: string): Session[]` — compound index query
- `create(data: NewSession): Session`
- `stop(id: string, endTime: number): Session` — sets `end_time` and `updated_at`
- `softDelete(id: string): void` — sets `is_deleted = true`
- `attachTerminal(sessionId: string, terminalId: string): void` — insert into session_terminals
- `getTerminals(sessionId: string): SessionTerminal[]`
- `isTerminalAttached(sessionId: string, terminalId: string): boolean`

**PulseRepository** (`pulse-repository.ts`):
- `create(data: NewPulse): ActivityPulse`
- `getLatestForSession(sessionId: string): ActivityPulse | undefined` — `ORDER BY timestamp DESC LIMIT 1`
- `getLatestForTerminal(terminalId: string): ActivityPulse | undefined`

**NoteRepository** (`note-repository.ts`):
- `create(sessionId: string, content: string): SessionNote`
- `findBySession(sessionId: string): SessionNote[]` — ordered by `created_at ASC`

**TagRepository** (`tag-repository.ts`):
- `addTag(sessionId: string, tag: string): SessionTag` — validates kebab-case, checks uniqueness
- `removeTag(sessionId: string, tag: string): void`
- `findBySession(sessionId: string): SessionTag[]`

**Index file** (`index.ts`):
- Export a `createRepositories(db)` factory that returns all repository instances
- This is the single import point for the service layer

### Task 4: Schema Push and Verification

**File(s):**
- `src/db/migrate.ts`

**Action:** Create a migration utility that applies the schema to the database.

1. Create `src/db/migrate.ts`:
   - Import `migrate` from `drizzle-orm/bun-sqlite/migrator` (if using generated migrations) OR use `drizzle-kit push` for dev
   - Export a `ensureSchema()` function that:
     - Calls `getDb()` to initialize the connection (which sets WAL mode)
     - Runs `bunx drizzle-kit push` equivalent programmatically, OR generates and applies migrations
   - For Phase 1, use `drizzle-kit push` approach (simpler, no migration files needed yet)
2. Add script to `package.json`: `"db:push": "bunx drizzle-kit push"`
3. The `getDb()` function in `client.ts` should call `ensureSchema()` on first initialization to auto-create tables on first use (no `tt init` required per CONTEXT.md decisions)
