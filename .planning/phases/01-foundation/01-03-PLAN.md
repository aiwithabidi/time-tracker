# Plan 01-03: Session Commands — start, stop, now, note, tag with Singleton Enforcement

**Phase:** 1 — Foundation
**Depends on:** Plan 01-01 (schema, repositories), Plan 01-02 (ProjectResolver, CLI entry, formatting)
**Requirements:** SESS-01, SESS-02, SESS-03, SESS-04, SESS-05, SESS-06, SESS-07

## Goal

Implement the five core session commands (start, stop, now, note, tag) with full singleton enforcement, multi-terminal attach via `TT_TERMINAL_ID`, stale session auto-close, and all output formatting per CONTEXT.md decisions. After this plan, a user can manually track time against projects end-to-end.

### Task 1: SessionService — Domain Logic

**Action:** Create the core session service that orchestrates session lifecycle. This is the domain layer — it calls repositories and ProjectResolver but contains no CLI-specific code.

**`src/core/session/types.ts`:**

```typescript
export interface SessionStartResult {
  action: 'created' | 'attached' | 'already_active'
  session: Session
  project: Project
  source: 'git' | 'alias' | 'dir' | 'prompt'
  staleSessionClosed?: { id: string; duration: number }  // if a stale session was auto-closed

  session: Session
  project: Project
  durationMs: number
}

export interface SessionNowResult {
  session: Session | null
  project: Project | null
  durationMs: number
  todayTotalMs: number
  todaySessionCount: number
}
```

```typescript
    super('No active session')
    this.name = 'NoActiveSessionError'

export class NoProjectFoundError extends Error {
```

**`src/core/session/session-service.ts`:**

Constructor takes: `{ sessionRepo, projectRepo, pulseRepo, noteRepo, tagRepo, terminalRepo, projectResolver, configLoader }`

Methods:

**`start(cwd: string, terminalId: string, options?: { projectOverride?: string }): SessionStartResult`**
1. Resolve project: use `projectOverride` slug OR `projectResolver.resolveProject(cwd)`
2. Ensure project in DB via `projectResolver.ensureProjectInDb()`
3. Check for stale sessions (any active session for this project where the latest pulse is older than 24 hours):
   - If found, auto-close it with `endTime = lastPulse.timestamp` (or `startTime + 1h` if no pulses)
   - Record in result as `staleSessionClosed`
4. Check for existing active session for this project (`sessionRepo.findActiveByProject`):
   - If found AND this terminal is already attached: return `{ action: 'already_active' }`
   - If found AND this terminal is NOT attached: attach terminal, create pulse, return `{ action: 'attached' }`
5. If no active session: create new session with:
   - `startTime: Date.now()`
   - `timezone: Intl.DateTimeFormat().resolvedOptions().timeZone` (IANA zone from system)
   - `source: 'manual'`
   - `rateAtTime: project.hourlyRate ?? null` (snapshot!)
   - Attach terminal
   - Create initial pulse with `sourceType: 'manual'`
   - Return `{ action: 'created' }`

**`stop(cwd: string, terminalId: string, options?: { projectOverride?: string }): SessionStopResult`**
1. If projectOverride: find active session for that project
2. Else: resolve project from cwd, find active session for it
3. If no active session found for resolved project, check ALL active sessions — if exactly one exists, stop that one (convenience: `tt stop` from any directory stops the only running session)
4. If no active sessions at all: throw `NoActiveSessionError` with suggestion `"Try 'tt start' to begin tracking"`
5. Stop the session: set `endTime = Date.now()`, calculate duration
6. Detach all terminals from the session
7. Return result with duration

**`now(cwd: string): SessionNowResult`**
1. Try to resolve project from cwd (but don't fail if outside a project)
2. If project resolved: look for active session for that project
3. Calculate today's total: query all sessions (active + completed) where `startTime >= startOfTodayUTC` for this project
4. For active sessions, duration = `Date.now() - startTime - idleDeductedMs`
5. If no project resolved: return all active sessions summary (today total across all projects)
6. Return `SessionNowResult`

**`addNote(cwd: string, content: string): { session: Session; note: SessionNote }`**
1. Find active session for resolved project
2. If no active session: throw `NoActiveSessionError` with suggestion `"Start a session first with 'tt start'"`
3. Create note via `noteRepo.create(session.id, content)`

**`addTag(cwd: string, tag: string): { session: Session; tag: SessionTag }`**
1. Validate tag format: must match `/^[a-z0-9-]+$/` (kebab-case, single word)
2. If invalid: throw with message "Tags must be lowercase kebab-case (e.g. 'billable', 'bug-fix')"
3. Find active session for resolved project
4. If no active session: throw `NoActiveSessionError`
5. Add tag via `tagRepo.addTag(session.id, tag)`
6. If tag already exists on session: return existing (idempotent, no error)

**`removeTag(cwd: string, tag: string): void`**
1. Find active session for resolved project
2. Remove tag via `tagRepo.removeTag(session.id, tag)`

**Terminal ID handling:**
- Read from `process.env.TT_TERMINAL_ID`
- If not set: generate a transient ID from `process.pid` with prefix `pid-` (allows basic usage without setup, but terminal persistence requires the env var)
- Log a one-time hint: "Set TT_TERMINAL_ID in your shell profile for multi-terminal tracking"

**`start.ts`:**
```typescript
export default {
  name: 'start',
  description: 'Start tracking time',
  options: {
    project: { type: 'string' as const, short: 'p', description: 'Override project slug' },
  },
  run: async (ctx: any) => {
    const terminalId = getTerminalId()
    const service = createSessionService()
    try {
      const result = service.start(process.cwd(), terminalId, {
        projectOverride: ctx.values.project,
      })
      if (result.staleSessionClosed) {
        output('info', chalk.dim(
          `Closed stale session (${formatDuration(result.staleSessionClosed.duration)} from earlier).`
        ))
      }
      if (result.action === 'created') {
        output('started', `Started ${chalk.bold(result.project.displayName)} ${chalk.dim(`(${result.source})`)}`)
      } else if (result.action === 'attached') {
        output('started', `Attached to ${chalk.bold(result.project.displayName)} ${chalk.dim(`(${result.source})`)}`)
      } else {
        // already_active — show current status instead of erroring (idempotent per CONTEXT.md)
        const duration = Date.now() - result.session.startTime - result.session.idleDeductedMs
        output('started', `${chalk.bold(result.project.displayName)}  ${formatDuration(duration)}`)
      }
    } catch (err) {
      handleCommandError(err)
    }
  }
}
```

**`now.ts`:**
```typescript
export default {
  name: 'now',
  description: 'Show current tracking status',
  options: {},
  run: async (ctx: any) => {
    const service = createSessionService()
    try {
      const result = service.now(process.cwd())
      if (result.session && result.project) {
        // Active session: "triangle project  duration (today: Xh Ym)"
        output('started', `${chalk.bold(result.project.displayName)}  ${formatDuration(result.durationMs)} ${chalk.dim(`(today: ${formatDuration(result.todayTotalMs)})`)}`)
      } else {
        // No active session: "circle No active session (today: Xh Ym across N sessions)"
        if (result.todayTotalMs > 0) {
          output('idle', `No active session ${chalk.dim(`(today: ${formatDuration(result.todayTotalMs)} across ${result.todaySessionCount} session${result.todaySessionCount !== 1 ? 's' : ''})`)}`)
        } else {
          output('idle', 'No active session')
        }
      }
    } catch (err) {
      handleCommandError(err)
    }
  }
}
```

**`note.ts`:**
```typescript
export default {
  name: 'note',
  description: 'Add a note to the current session',
  options: {
    message: { type: 'string' as const, short: 'm', description: 'Note text' },
  },
  run: async (ctx: any) => {
    const service = createSessionService()
    // Support both `tt note -m "text"` and `tt note "text"` (positional)
    const content = ctx.values.message || ctx.args?.[0]
    if (!content) {
      errorOutput('Note text is required', "tt note -m \"what I'm working on\"")
      process.exit(1)
    }
    try {
      const { session } = service.addNote(process.cwd(), content)
      output('info', chalk.dim('Note added'))
    } catch (err) {
      handleCommandError(err)
    }
  }
}
```

**`tag.ts`:**
```typescript
export default {
  name: 'tag',
  description: 'Add or remove a tag on the current session',
  options: {
    add: { type: 'string' as const, short: 'a', description: 'Add tag' },
    remove: { type: 'string' as const, short: 'r', description: 'Remove tag' },
  },
  run: async (ctx: any) => {
    const service = createSessionService()
    try {
      if (ctx.values.remove) {
        service.removeTag(process.cwd(), ctx.values.remove)
        output('info', chalk.dim(`Removed tag: ${ctx.values.remove}`))
      } else {
        // Support `tt tag billable` (positional) or `tt tag -a billable`
        const tag = ctx.values.add || ctx.args?.[0]
        if (!tag) {
          errorOutput('Tag name is required', "tt tag billable")
          process.exit(1)
        }
        service.addTag(process.cwd(), tag)
        output('info', chalk.dim(`Tagged: ${tag}`))
      }
    } catch (err) {
      handleCommandError(err)
    }
  }
}
```

**Shared helpers** (add to `src/cli/helpers.ts`):
- `getTerminalId(): string` — reads `TT_TERMINAL_ID` or falls back to `pid-${process.pid}`
- `createSessionService(): SessionService` — wires up DB, repos, and service (lazy init)
- `handleCommandError(err: unknown): void` — maps domain errors to formatted output:
  - `NoActiveSessionError` -> `errorOutput(err.message, err.suggestion)`
  - `NoProjectFoundError` -> `errorOutput(err.message, err.suggestion)`
  - Unknown -> `errorOutput('Something went wrong', 'Check ~/.tt/tt.db exists')`
