### Minor Observations (not blocking)

1. **SEC-01/02 partial gap in source hooks:** The `src/hooks/*.sh` files checked into the repo lack `tr -cd` sanitization. Only the scripts generated by `tt setup` (in `setup.ts`) include it. If someone deploys from `src/hooks/` directly, they get unsanitized hooks. Consider updating the source hook files or adding a note that `tt setup` is the canonical deployment method.

2. **COR-05 type residue:** The `'prompt'` and `'dir'` source types remain in the `ResolvedProject` type union (`project-resolver.ts:9`, `types.ts:7`) even though no code path ever assigns them. This is cosmetic dead code in the type system.
